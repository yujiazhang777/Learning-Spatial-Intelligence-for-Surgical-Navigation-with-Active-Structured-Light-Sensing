# Learning Spatial Intelligence for Surgical Navigation with Active Structured Light Sensing

Research code and visualization tools associated with **Learning Spatial Intelligence for Surgical Navigation with Active Structured Light Sensing**.

This project includes active structured-light surface reconstruction, marker-based IORT device tracking, and visualization of reconstructed surfaces and device trajectories in a shared coordinate frame.
